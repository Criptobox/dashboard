¿Cómo conecto Supabase?
  1. Crea un proyecto gratis en supabase.com.
  2. En SQL Editor ejecuta supabase.sql (antes cambia el correo del final por el tuyo).
  3. En Authentication → Users crea tu usuario con ese mismo correo.
  4. En Project Settings → API copia la Project URL y la clave anon public en config.js.
