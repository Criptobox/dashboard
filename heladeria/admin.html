Conecta Supabase

El panel necesita una base de datos. Sigue estos pasos (también están en el README.md):

  1. Crea un proyecto gratis en supabase.com.
  2. En SQL Editor pega y ejecuta el archivo supabase.sql (antes cambia el correo del final por el tuyo).
  3. En Authentication → Users crea tu usuario con ese mismo correo y una contraseña.
  4. En Project Settings → API copia la Project URL y la clave anon public en config.js.
  5. Recarga esta página.
